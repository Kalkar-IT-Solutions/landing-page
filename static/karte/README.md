# Karte Kalkar und Umgebung

Vektorkacheln (OpenMapTiles-Schema, Zoom 0–14) für Kalkar Kompakt, Ausschnitt
6,10–6,52 °O / 51,62–51,86 °N (etwa Kleve, Rees, Uedem, Xanten-Nord), dazu die
Glyphen für die Beschriftung. Die App liest sie unter `/karte/kalkar/{z}/{x}/{y}.pbf`
und `/karte/fonts/{Schrift}/{Bereich}.pbf`.

- Kartendaten: © OpenStreetMap-Mitwirkende, ODbL 1.0 (https://www.openstreetmap.org/copyright)
- Kacheln erzeugt mit Planetiler (Apache-2.0) aus dem Geofabrik-Auszug Regierungsbezirk Düsseldorf
- Schrift: Noto Sans, SIL Open Font License 1.1 (fonts/OFL.txt), Glyphen aus protomaps/basemaps-assets

Erneuern: siehe `tool/map/README.md` im Repository kalkar-kompakt.
