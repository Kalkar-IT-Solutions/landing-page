Willkommen bei Redaktion. Auf der Startseite Ihrer Website sehen Sie als Verantwortliche oder
Verantwortlicher eine Liste **Erste Schritte**. Was Redaktion selbst erkennt, ist schon
abgehakt; den Rest haken Sie ab, sobald er erledigt ist.

1. **Passwort setzen**: Über den Einladungslink haben Sie ein Passwort vergeben. Unter
   *Konto* können Sie es jederzeit ändern oder einen Passkey einrichten.
2. **Zweite Person einladen**: Damit Ihre Website nicht an einer Person hängt, laden Sie
   unter *Zugänge* eine Kollegin oder einen Kollegen ein ([mehr dazu](kb:team)).
3. **Erste Änderung veröffentlichen**: Öffnen Sie einen Bereich, ändern Sie einen Text und
   tippen Sie auf *Veröffentlichen* ([mehr dazu](kb:veroeffentlichen)).
4. **Impressum prüfen**: Stimmen Anschrift, Kontakt und Vertretung? ([mehr dazu](kb:impressum))
5. **Hilfe lesen**: Diese Seite haben Sie gefunden.

Die Liste lässt sich ausblenden, wenn Sie sie nicht mehr brauchen.
